# pr-assets

Screenshots and other media referenced from pull requests in
[virtue-initiative/virtue-initiative](https://github.com/virtue-initiative/virtue-initiative).

The repo is public because GitHub's image proxy can't authenticate to a private
one — a `raw.githubusercontent.com` link from here is what makes an image render
inline in a PR body.

One directory per issue or PR. Nothing here is built or deployed; deleting a
directory only breaks the images in whichever PR referenced it.
